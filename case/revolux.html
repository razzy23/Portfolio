Stage 1

The concept

RevolUX 3.0 is an inter-university UI/UX designathon. As project lead I came up with the design concept: a retro arcade, built from abstract technical elements and the feel of a 1980s game screen. I designed the key pieces, and the team carried the system across the rest of the campaign.

Echo type

Headlines repeat as outlines, like a score flashing on screen.

>_ DESIGN TIPS▭ ▣ ✕

Terminal windows

Body copy sits inside command-line windows instead of plain text boxes.

Wireframe mesh

Warped grids and perspective floors run behind every post and tie the set together.

Duotone hardware

CRT monitors, arcade cabinets and VR headsets, generated with Leonardo AI and finished in Photoshop.

The merch
